# DentalLab

Sistema integrado de gestão para o **Laboratório Catarina Domingos - Laboratório de Prótese Dentária**.

Projeto desenvolvido no âmbito da unidade curricular **Projeto Integrado IV** da Licenciatura em Tecnologias e Design de Multimédia (ESTGV), ano letivo 2026/2027.

> 🚧 **Em desenvolvimento** - o projeto encontra-se numa fase inicial.

## Objetivo

Plataforma digital para centralizar a informação do laboratório e acompanhar todo o ciclo de vida dos trabalhos, desde o pedido feito pela clínica até à entrega.

## Componentes

| Componente | Descrição | Pasta |
| --- | --- | --- |
| Portal de Backoffice | Gestão de clientes, colaboradores e trabalhos (Administrador, Colaborador e Cliente) | `frontend/` |
| Website institucional | Página de apresentação do laboratório | `frontend/` |
| Aplicação móvel | Criação e acompanhamento de trabalhos (planeada) | — |
| Backend / API | Serviço de dados da plataforma | `backend/` |
| Base de dados | Modelo conceptual e modelo físico | `ModelosBaseDeDados/` |

## Tecnologias

- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **Backend:** Node.js, Fastify, TypeScript
- **Base de dados:** PostgreSQL
- **Aplicação móvel:** Flutter (planeada)
